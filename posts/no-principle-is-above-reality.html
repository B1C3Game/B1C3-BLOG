Doctrine

No Principle Is Above Reality

I replaced a provocative slogan with a usable rule: respect defaults, inspect assumptions, and let evidence decide.

Published: 2026-06-29

I used to say: "Nothing is sacred."

It sounded bold, but it created confusion.

Some people heard, "Everything is negotiable." Others heard, "I can ignore criticism when it is inconvenient." Neither interpretation is what I mean.

The principle I actually stand behind is this:

No principle is above reality.

Why the Old Phrase Failed

"Nothing is sacred" compresses too much into three words.

It can be read as a libertarian free-for-all:

  • Rules are optional.
  • Morality is optional.
  • Constraints only matter when I like them.

It can also be used as doctrine-as-pretext:

  • I claim to be anti-dogma.
  • Then I quietly exempt myself from scrutiny.

Both are failure modes.

The Actual Doctrine

This principle has two layers.

1) Respect the defaults

Defaults exist for a reason. Most of them encode hard-won lessons.

  • Traffic laws reduce chaos.
  • Aviation checklists reduce fatal errors.
  • Medical protocols reduce preventable harm.

The default should be: follow the default.

2) Override only when reality demands it

Sometimes the map stops matching the territory.

The process assumes X.
Reality is now Y.

If following the default increases harm, then the default has failed in that context.

That is when override becomes responsible, not rebellious.

Rules are not bad.
Rules are tools.
Tools are judged by outcomes.

A Practical Protocol

If I had to make this operational, it would be:

  1. Start from the default.
  2. State the assumption the default depends on.
  3. Test that assumption against current evidence.
  4. Override only if mismatch is clear and stakes justify change.
  5. Record what happened so the system can learn.

This avoids both extremes:

  • Blind obedience.
  • Random anti-structure behavior.

The Hard Part: Self-Application

The principle means nothing if it only applies to other people.

If my own framework cannot be inspected, then it has already become dogma.

This includes B1C3, my language, my methods, and my favorite narratives.

If reality contradicts them, they must bend.

Close

"Nothing is sacred" was the rough signal.

"No principle is above reality" is the precise form.

Principles guide.
Evidence decides.

Defaults deserve respect.
Reality gets the final vote.
