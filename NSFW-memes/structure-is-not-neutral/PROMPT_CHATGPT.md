# ChatGPT Prompt: Structure Is Not Neutral

## Turn A (Planning Only)

Stop after text output. Do not generate any image in this turn.

Task:
Design an educational infographic poster that shows how structure changes what information is visible.

Core doctrine:
Every structure preserves some information and destroys other information. The frame that produces the prompt changes the image. The structure determines what evidence can be gathered.

Four structures to show:
1. Direct conversation — includes: tone, context, hesitation, implicit weight. Loses: repeatability
2. Structured dataprompt — includes: consistency, inspectability. Loses: spontaneity, narrative, emotional weight
3. Reverse-engineered prompt — includes: your interpretation of the image. Loses: original intent, drifts on regeneration
4. SPOC (Single Point of Contact) — includes: coordination. Loses: perspective diversity, direct signal from reality

The central question shown in the image:
"What information did this structure make expensive to see?"

Guardrails:
- Not anti-structure. Structure is necessary and useful.
- Awareness, not rejection.
- Show each structure as a lens, not as failure.
- Neutral analytical tone with subtle satirical edge.
- No personal blame framing.

Return only:
1. Layout blueprint (max 5 zones)
2. Visual representation for each structure type
3. In-image text map with max word counts
4. Risk checklist (4 bullets)
5. One sentence confirming feed-preview readability
