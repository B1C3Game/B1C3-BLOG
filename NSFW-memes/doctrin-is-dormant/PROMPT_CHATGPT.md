# ChatGPT Prompt - Doctrine Is Dormant Capability

## Intent

Doctrine is a standby capability that should be used deliberately when reality changes, not treated as a last-resort panic move.

## Primary Prompt

Use this prompt in ChatGPT web image generation:

```
Create a cinematic mission-control scene inspired by a space agency operations room.

Core concept:
- Doctrine is dormant capability, activated when context changes.
- "Nothing is sacred" means re-examine assumptions, not destroy principles.

Visual requirements:
- Foreground control console labeled "B1C3 DOCTRINE CONTROLS".
- Matrix of worn-use buttons grouped by doctrine domains:
	- GOAL CLARITY
	- REALITY CHECK
	- OWNERSHIP
	- CAPABILITY
	- CONSTRAINTS
- Adjacent hero panel with a large green button labeled "NOTHING IS SACRED".
- Supporting text near button:
	- RE-EXAMINE ASSUMPTIONS.
	- CONTEXT OVER COMFORT.
	- REALITY OVER PRESTIGE.
- Footer plaque:
	- USE OFTEN. USE WISELY. NOT A LAST RESORT.
- Add a small sticky note reminder:
	- Not when things are easy. When things change.

Environment:
- Professional mission-control room with operators and large status screens.
- Calm nominal operations, no panic disaster vibe.

Art direction:
- High-detail cinematic realism.
- Cool industrial palette with green accent for doctrine activation.
- Console body clean, button caps show repeated wear.
- Typography legible at social-feed scale.

Output:
- One high-resolution poster-style image suitable for web embedding.
```

## Negative Constraints

- No copyrighted characters.
- No explicit violence.
- No glowing red panic aesthetic.
- No "press to destroy" semantics.
- No cluttered unreadable microtext.

## Variant Prompts

### Variant A: Cleaner

```
Keep same scene, reduce button text density by 40 percent.
Keep only domain labels and one action verb per row.
```

### Variant B: More aggressive

```
Increase contrast between nominal mission room and doctrine panel.
Keep language procedural, not chaotic.
```

### Variant C: Minimal

```
Use same composition with fewer screen details and larger doctrine text blocks.
Keep the green button as single focal anchor.
```
