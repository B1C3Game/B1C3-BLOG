# Meme Card: Four Villains That Block Genius Process

## Term

Four Villains That Block Genius Process

## One-line Definition

Most insight failure is barrier failure, not intelligence failure.

## Full Definition

This poster names four blockers that interrupt process-level insight practice:

- Imposter syndrome
- Fear of grandiosity
- Lack of tools
- Context load

The doctrine is de-shaming and actionable: name the barrier, then design around it.

## When To Use

- Someone reads process failure as personal inadequacy.
- A team has insight but no stable capture-transfer workflow.
- You need a bridge from "what works" to "what blocks it" in the POC-08 series.

## Not This

This is not diagnosis or mental-health labeling. It is an educational barrier map for practice design.

## Caption Options

- Name the barrier, reduce the shame.
- Insight dies where tools and permission are missing.
- Blockers are design problems, not identity verdicts.

## Post Hook

You can teach a strong method and still watch people fail to use it. This poster shows why: barriers consume attention before process can even start.
