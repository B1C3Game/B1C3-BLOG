# Meme Card - The Original Question

## Term

The Original Question

## One-line Definition

A meme about process growth that leaves the founding question behind.

## Urban Dictionary Style Meaning

This meme exposes research drift. Teams build increasingly sophisticated frameworks, departments, and language layers, while the initial question is no longer actively checked. It applies wherever institutional complexity outruns purpose clarity.

## When To Use

- A project accumulates meta-work faster than answers.
- Stakeholders confuse formal complexity with progress.
- You need to reintroduce mission clarity without personal blame.

## Not This

This is not anti-research or anti-theory. It is anti-purpose drift.

## Caption Options

- We scaled the framework, not the question.
- Busy is not the same as anchored.
- Original question, still unchecked.

## Post Hook

Complex work needs structures, but structure can become self-justifying. This meme is a checkpoint tool: before adding another layer, verify whether the original problem is still being answered.
