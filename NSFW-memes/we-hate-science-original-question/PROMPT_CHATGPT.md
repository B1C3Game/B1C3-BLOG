# ChatGPT Prompt - The Original Question

## Intent

Show institutional research drift where complexity expands and the founding question gets abandoned.

## Primary Prompt

Use this prompt in ChatGPT web image generation:

```
Create a satirical institutional corridor scene with many advanced departments.
Departments should imply meta-layer growth, for example: Framework Integration, Recursive Foundations, Notation Studies, Model Extensions.
Foreground detail: an abandoned clipboard labeled "ORIGINAL QUESTION" with an unchecked box.
Tone: witty but fair, no character attacks, no anti-science framing.
Style: high legibility, medium detail density, social-media readability.
Avoid: tiny text overload, logos, copyrighted characters, chaotic clutter.
Output: one high-resolution 4:5 image suitable for posting.
```

## Negative Constraints

- No accidental logos or copyrighted characters.
- No unreadable tiny text.
- No style drift from concept intent.

## Variant Prompts

### Variant A: Cleaner

```
Reduce department labels to three signs only.
Keep clipboard large and foregrounded.
Use fewer characters for cleaner readability.
```

### Variant B: More aggressive

```
Increase department count and signage complexity.
Make the unchecked original-question clipboard visually isolated.
Preserve non-hostile tone.
```

### Variant C: Minimal

```
Single hallway with one distant crowd and one foreground clipboard.
Text only: "ORIGINAL QUESTION" and an empty checkbox.
```
