# ChatGPT Prompt - Mirror Doctrine

## Intent

Make the viewer instantly understand the joke: institutions can say nobody gets left behind while building systems that punish anyone who does not fit the template.

## Primary Prompt

Use this prompt in ChatGPT web image generation:

```
Create a single poster-style satirical civic propaganda image in Swedish language.
Core concept: Mirror Doctrine, care language used to justify control.
Main slogan in large type: "INGEN LAMNAS UTANFOR. INGEN LAMNAS IFRED."
Secondary framing: "Substans fore form" and "Kontroll ar karlek".
Scene: formal institutional hall, central spokesperson at podium, disciplined staff around them, banners and policy boards.
Tone: deadpan, bureaucratic, polished, unsettling but readable, not chaotic.
Visual style: premium print-poster look, cinematic lighting, balanced composition, deep navy, cream, muted red accents.
Message clarity rule: at first glance viewers must understand this is about performative empathy becoming administration and surveillance.
No real logos, no copyrighted IP, no celebrity likenesses.
High resolution vertical poster composition.
```

## Negative Constraints

- Avoid gore or explicit violence.
- Avoid unreadable micro text blocks.
- Do not make it campy comedy, keep deadpan seriousness.
- No real institutions, parties, or government insignia.

## Variant Prompts

### Variant A: Cleaner Governance Look

```
Same concept as primary prompt, but reduce crowd density by 40 percent.
Use fewer signs, stronger whitespace, and one dominant slogan block.
Keep the irony in the contrast between empathy language and control procedure.
```

### Variant B: Harder Satire

```
Same concept as primary prompt, but increase bureaucratic absurdity.
Add visible checklist culture, numbered compliance steps, and uniform ritual gestures.
Main subtitle: "Empati standardiserad. Omsorg kvalitetsakrad."
Keep legibility and premium poster style.
```

### Variant C: Minimal Poster

```
Minimalist redesign with one leader figure, two side banners, one policy board.
Limit copy to main slogan and one supporting line.
Keep sharp typography and muted institutional palette.
```
