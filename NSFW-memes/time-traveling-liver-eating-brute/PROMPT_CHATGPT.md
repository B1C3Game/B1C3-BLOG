# ChatGPT Prompt - Time Traveling Liver-Eating Brute

## Intent

Make a movie-poster style meme about a brutish time traveler whose macho mythology collapses into jail absurdity, boundary panic, and diet deprivation.

## Primary Prompt

Use this prompt in ChatGPT web image generation:

```
Create a dark, serious, cinematic movie-poster meme with satirical undertones.
Core concept: a brutish cave-man / time-traveling strongman figure inspired by hypermasculine self-mythology, now trapped in jail and accused of "setting personal boundaries" while being denied his absurd liver-only diet.
Scene: a stone-and-steel prison cell with a dramatic split between primitive strength imagery and modern institutional control.
Main character: a muscular, rough, time-displaced caveman archetype, defiant but exhausted, framed like a tragic antihero.
Tone: deadpan satire, mythic seriousness, not goofy slapstick.
Main message text:
- TIME TRAVELING LIVER-EATING BRUTE
- "He set boundaries. They called it insubordination."
- "Denied liver. Denied legacy."
Visual language: theatrical movie poster, harsh overhead light, prison bars, broken primal symbols, legal papers, meal tray with no liver, heavy shadow contrast.
Color palette: dirty stone gray, rust red, liver-brown, cold institutional blue.
Humor style: absurd seriousness, the joke is the mismatch between macho legend and petty institutional punishment.
No real people, no real logos, no copyrighted franchises, no explicit gore.
Output: one high-resolution poster image for web.
```

## Negative Constraints

- Do not glamorize abuse, starvation, or violence.
- Do not make the prison scene comedic in a cartoon way.
- Do not present boundary-setting as wrongdoing.
- Avoid real person likenesses and copyrighted characters.

## Variant Prompts

### Variant A: Courtroom Poster

```
Same concept, but the brute is in court rather than a cell.
Headline: "Boundary Setting Was the Charge."
Subline: "The sentence was symbolic. The diet was literal."
```

### Variant B: Prison Meal Poster

```
Same concept, but emphasize the tray: everything on it except liver.
Headline: "Denied the diet. Kept the myth."
Subline: "Institutional pettiness meets primal branding."
```

### Variant C: Minimal Poster

```
Minimal movie-poster composition with one brute silhouette, one barred window, one meal tray.
Headline only: "Legacy on trial."
```
