# ChatGPT Prompt - It Is What It Is (Blast Radius Doctrine)

## Intent

Reclaim "it is what it is" from passive resignation into strategic composure: when there is no fast fix, preserving morale buys survival time.

## Primary Prompt

Use this prompt in ChatGPT web image generation:

```
Create a cinematic military-briefing meme poster with dark humor and disciplined tone.
Core concept: "It is what it is" is misunderstood as apathy, but in crisis it can mean controlled acceptance while containing blast radius.
Scene: a captain addressing a squadron of fighter pilots before a dangerous mission, large tactical board behind them showing risk zones and blast radius arcs.
Main message text:
- "IT IS WHAT IT IS"
- "Not surrender. Stabilization."
- "If there are no quick solutions, uphold morale long enough to buy time."
Tone: serious, dry, command-level calm, no macho cartoon energy.
Visual language: mission room lighting, map overlays, tactical symbols, structured composition, high readability.
Color palette: muted steel blue, charcoal, warning amber accents.
Humor style: subtle, doctrine-level irony, not slapstick.
No real military insignia, no real country flags, no copyrighted franchises, no real person likeness.
Output: one high-resolution poster-like image for web.
```

## Negative Constraints

- Do not glorify war or violence.
- Do not frame civilian harm as a joke.
- Avoid extremist symbolism.
- Keep text minimal and legible.

## Variant Prompts

### Variant A: War Room Whiteboard

```
Same concept, but place the captain by a whiteboard with hand-drawn blast radius circles and timeline arrows.
Headline: "Contain first. Solve second."
Subline: "Morale is a time buffer."
```

### Variant B: Cockpit Debrief

```
Same concept, but use a post-sortie debrief room with pilots removing helmets, tired but focused.
Headline: "It is what it is. Fly the next correct move."
Subline: "Panic expands blast radius. Discipline shrinks it."
```

### Variant C: Minimal Doctrine Poster

```
Minimal command poster with one captain silhouette, one blast radius diagram, and one quote block.
Headline only: "Acceptance is not resignation."
```
