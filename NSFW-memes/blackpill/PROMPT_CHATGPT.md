# ChatGPT Prompt - Blackpill Is A Moment, Not A Home

## Intent

A geeky mentor character reframes blackpill from fixed identity into a temporary realization point, then pushes toward agency.

## Primary Prompt

Use this prompt in ChatGPT web image generation:

```
Create a single high-impact meme poster in a cinematic "red pill / blue pill" homage style, but original and non-copyrighted.
Main character: a sharp, geek-coded mentor (glasses, practical jacket, analytical vibe) standing in front of floating data panels.
Tone: serious, reflective, slightly ironic, but constructive.
Core message:
- "Actually, blackpill is not a permanent choice. It is an AHA moment of realization."
- "Fearing blackpill can lead to victimhood."
Scene language: dark-to-light gradient, left side deterministic doom symbols, right side agency/action symbols.
Visual metaphor: realization as a phase transition, not an identity label.
Typography style: clean bold sans-serif headline, readable subtitle, no clutter.
No direct Matrix references, no copyrighted character likeness, no studio logos.
Output: one poster-like image, web-ready, clear message at first glance.
```

## Negative Constraints

- Do not glamorize nihilism, hopelessness, or harm.
- Do not portray any group as inferior or biologically doomed.
- Avoid cringe "edgelord" aesthetics.
- Keep text readable and short.

## Variant Prompts

### Variant A: Data Lab Angle

```
Same core concept, but place the mentor in a minimalist data-lab environment with transparent charts and decision trees.
Headline: "Aha is a doorway, not a prison."
Subline: "Insight without agency becomes victimhood."
```

### Variant B: Street Poster Angle

```
Same core concept, but style as a wheatpaste urban poster with torn edges and layered warning labels.
Headline: "Blackpill is a signal, not a sentence."
Subline: "Interpret. Then act."
```

### Variant C: Minimal Editorial Angle

```
Same core concept, but use one mentor portrait and one split-color backdrop.
Headline only: "Realization is not resignation."
No extra decorative elements.
```
