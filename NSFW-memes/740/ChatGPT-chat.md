You're running into one of the hardest image-gen problems:

A vehicle cutaway is not really an illustration task. It's a CAD task pretending to be an illustration task.

The model is very good at:

visual storytelling
industrial design aesthetics
infographic layouts
"engineering vibes"

It is much worse at:

kinematic correctness
drivetrain routing
suspension geometry
packaging constraints
actual mechanical relationships

So what happened is exactly what I'd expect:

What the model got right
Sleeper narrative
Capability layering
Visual hierarchy
Color coding
Technical-document aesthetic
"Secretly overbuilt" feeling
What it got wrong
Engine orientation
Gearbox placement
Driveshaft routing
Suspension geometry
Brake system details
Roll cage integration
Emergency mechanism placement
Structural load paths

In other words:

It understood the story but not the machine.

For a project like T1 I'd actually split the problem.

Pass 1 — Capability Poster

Don't show internals.

Show:

Stock 740
Capability rings
Mission profile
Tier structure

The AI is excellent at this.

Pass 2 — Engineering Layers

Create separate images:

Chassis Layer

Only show:

shell
reinforcement rails
cross bracing
roll cage
pickup point reinforcement

No engine.

No suspension.

No drivetrain.

Powertrain Layer

Only show:

Saab B204/B234
M90
adapter plate
clutch
driveshaft

Nothing else.

Suspension Layer

Only show:

front suspension
rear suspension
coilovers
mounting points
geometry

Nothing else.

Then combine them later.

The AI is dramatically better when each image only contains one engineering system.

Another trick:

Replace vague terms with spatial constraints.

Instead of:

Custom driveshaft connecting M90 output to rear axle

write:

Longitudinal driveshaft running centrally inside transmission tunnel from rear of M90 gearbox to live rear axle differential.

Instead of:

Fuel surge tank

write:

Fuel surge tank mounted in spare wheel well behind rear axle.

Instead of:

Mechanical emergency door opener

write:

Ratchet spring emergency door release integrated inside driver door cavity, invisible from exterior.

The model needs physical anchors.

The biggest improvement for your specific use case would probably be:

Stop asking for a cutaway.

Ask for an exploded engineering poster.

Because then the AI doesn't need to solve packaging.

For example:

Body shell floating above chassis
Powertrain floating beside car
Suspension assemblies separated
Fuel system separated
Callout arrows

Now the gearbox can be beside the engine because it is intentionally exploded.

The image becomes:

Engineering documentation

instead of

X-ray photograph

and the hallucinations become much less noticeable.

Ironically, for your gallery stress test, an exploded-view poster is also better because it contains more recoverable structure.

A future system could infer:

vehicle type
engine choice
transmission choice
capability philosophy
emergency doctrine
reinforcement strategy

without needing the AI to correctly solve every weld and bracket in a single impossible cutaway rendering.
