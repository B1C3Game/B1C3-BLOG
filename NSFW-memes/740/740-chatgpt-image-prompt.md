# 740 Project — ChatGPT Image Prompts (Layered Strategy)

## The Problem with Full Cutaways

AI image models excel at **visual storytelling** but hallucinate **mechanical accuracy**. A single full-cutaway request produces:
- Wrong engine orientation
- Gearbox in impossible locations
- Driveshaft routing that doesn't connect
- Suspension geometry that's incoherent
- Components floating in space

**Solution:** Generate 4 focused images separately, each showing only what the AI can render accurately.

---

## Strategy: Layered Image Generation

### Layer 1: Capability Poster ← **START HERE**
Stock 740 with mission rings and capabilities overlaid. AI excels at this.

### Layer 2: Chassis Structure
Only reinforcement, bracing, roll cage. No drivetrain/suspension confusion.

### Layer 3: Powertrain
Only engine, gearbox, adapter, clutch, driveshaft. Focused mechanical view.

### Layer 4: Suspension
Only suspension components and geometry. No other systems to hallucinate.

**Result:** You can composite these 4 images side-by-side or layer them to show the complete engineering story accurately.

```
Overlay transparent capability rings radiating from the vehicle, each labeled:

Next ring: "Emergency Resilience"

At the center of the vehicle, add a small seal: "740 Project - Built for Any Emergency"

At the bottom, add a banner with the mission statement:
"Sleeper design means it arrives unnoticed. Built engineering means it arrives prepared."

Style: Clean, professional, infographic aesthetic. Lighting should be studio-quality.
Color palette: Muted vehicle colors with accent rings in blue, orange, and silver.
```

## Prompt 2: Chassis Reinforcement Layer

```
Technical diagram of a Volvo 740 Combi chassis structure. Show ONLY:

- Factory unibody skeleton in light gray wireframe
- Heavy-duty steel reinforcement rails (metallic silver, prominent)
- Cross-bracing and triangulation points (shown in bright orange)
- Roll cage elements welded into pillars and roof (gunmetal blue)
- Strut tower braces (orange accent)
- Floor pan reinforcement rails and rocker panel bracing (silver)

Cutaway view showing the interior structure clearly.
No engine. No suspension. No drivetrain. No interior.

Style: Technical CAD diagram with color-coding.
Lighting: Neutral technical lighting.
Include a banner: "Chassis Layer - Structural Reinforcement"
```

```

- Saab B204/B234 turbo engine (shown from front angle, mounted horizontally)

- Custom driveshaft extending from gearbox output rearward to rear axle

No chassis. No suspension. No other systems.

Style: Technical CAD cutaway.
Color-coding: Engine block (dark red), gearbox (dark blue), custom fabrication (orange).
Include a banner: "Powertrain Layer - Saab B204 + M90 Manual"

```

```
- Springs and dampers highlighted in red
```

## How to Use

1. **Start with Prompt 1** (Capability Poster) — This will be your primary image
2. Generate Prompts 2-4 as supporting technical images
3. Composite them in a grid or presentation layout
4. **Result:** Complete visual story that's both accurate and compelling
