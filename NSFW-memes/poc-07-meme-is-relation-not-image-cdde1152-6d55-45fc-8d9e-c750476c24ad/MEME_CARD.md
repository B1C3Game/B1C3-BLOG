# Meme Card - Meme Is Relation, Not Image

## Term

Meme Is Relation, Not Image

## One-line Definition

A meme is a cultural pattern that replicates between people; images are optional carriers, not the meme itself.

## Urban Dictionary Style Meaning

This meme flips the common internet shortcut where people call the file "the meme". The point is that replication happens in shared rhythm, reference, and social interpretation. The image can trigger transmission, but people stabilize and carry it.

## Core Thesis

- Carrier is optional: image, text, audio, gesture, chant.
- Replication is social: shared frame, repeated pattern, mutual recognition.
- Culture came first: meme behavior predates modern image macros.

## When To Use

- When discussion collapses meme theory into pure image format.
- When teams optimize visual assets but ignore social context.
- When someone mistakes distribution for cultural replication.

## Not This

Not anti-image. Images matter.
This is anti-reduction: image-only framing hides the human layer.
