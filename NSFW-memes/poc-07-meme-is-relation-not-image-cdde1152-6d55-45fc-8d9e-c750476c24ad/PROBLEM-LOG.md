# POC-07 Problem Log

This log documents all major issues encountered during generation and how they were resolved.

## Issue 1: Render Timeouts

- Observed: long generation runs ending in failure.
- Resolution: compact fallback prompts, reduced contradictory constraints.

## Issue 2: Gatekeeping Interpretation

- Observed: outputs framed one group as "getting it" and the other as lacking intelligence.
- Resolution: rewrote prompts to encode context mismatch, not human ranking.

## Issue 3: Lonely-Outcast Visual Shortcut

- Observed: model used isolated person as failure symbol.
- Resolution: explicit ban on lonely-outcast trope and requirement for groups in both lanes.

## Issue 4: Screen-Centric Dominance

- Observed: visuals still centered screens/phones despite culture-first thesis.
- Resolution: composition budgets with no-phone/no-device instructions.

## Issue 5: Thesis Drift in Prompt 5

- Observed: line "file is necessary" contradicted campaign doctrine.
- Resolution: replaced with bait-and-switch reveal, "It was culture all along," and optional-carrier branch.

## Outcome

- Final selected output aligns with culture-first framing.
- Full iteration retained to demonstrate reproducible correction path.
