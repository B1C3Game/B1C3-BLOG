# ChatGPT Prompt - Feelings Allowed, Residency Denied

## Intent

Anger can be processed without being promoted to identity or permanent residence.

## Primary Prompt

Use this prompt in ChatGPT web image generation:

```
Create a highly detailed satirical illustrated poster of an amusement park called "REVENGE LAND".

Core message:
- Anger is allowed as temporary emotional processing.
- Long-term revenge rumination is not allowed to become identity.

Visual style:
- Hand-painted storybook/comic realism.
- Warm carnival colors, readable typography, humorous but emotionally intelligent.
- Family-friendly appearance with psychologically sharp text details.
- Portrait composition, high detail, social-share ready.

Required scene elements:
- Large entrance sign: "REVENGE LAND"
- Subtitle: "A family destination for temporary emotional processing"
- Multiple attractions with signs that represent cognitive traps:
	- "The Imaginary Argument Arena"
	- "The Petty Victory Roller Coaster"
	- "The Hall of Selective Memory"
	- "The Catastrophic Future Simulator"
	- "The Department of Vindication"
	- "The Pettiness Spin Zone"
- Characters visibly engaging in each trap in funny but relatable ways.

Required moral-resolution signage near exit:
- "Thank you for visiting"
- "ANGER IS WELCOME. RESIDENCY APPLICATIONS DENIED."
- Rules equivalent to:
	- no permanent residence
	- no rumination loops
	- no anchoring your identity
- Exit line equivalent to:
	- "Come for a few hours. Leave lighter."
	- "EXIT HAPPIER"

Tone constraints:
- Compassionate satire.
- Do not shame anger itself.
- Critique obsessive revenge loops, not emotional expression.

Typography constraints:
- All key signs must be legible at social feed zoom.
- Keep text density high but still readable.

Output:
- One high-resolution poster-style image suitable for web embedding.
```

## Negative Constraints

- No real brands or copyrighted characters.
- No gore or explicit violence.
- No mean-spirited humiliation.
- No unreadable tiny text for key doctrine lines.
- Avoid dark nihilistic atmosphere.

## Variant Prompts

### Variant A: Cleaner

```
Keep scene and message, reduce sign count by 30 percent.
Make governance sign larger at bottom.
```

### Variant B: More aggressive

```
Keep attractions and increase queue length at vindication booth.
Preserve compassionate tone.
```

### Variant C: Minimal

```
Replace revenge wording with resentment wording while keeping same structure and exit doctrine.
```
