# ChatGPT Prompt - Schrodingers Ansvar

## Intent

Make the viewer instantly get the joke: everyone touched the decision, nobody owns the outcome.

## Primary Prompt

Use this prompt in ChatGPT web image generation:

```
Create a retro-corporate satirical poster triptych in Swedish language.
Core concept: Schrodingers Ansvar, responsibility exists in every meeting but disappears at delivery.
Main headline: "SCHRODINGERS ANSVAR".
Subline: "Bevis fore erkannande" and "Om det inte kan bevisas, vem bar det da?"
Primary panel: formal meeting room with one empty chair labeled responsibility while teams circulate tasks.
Secondary panels: audit collapse, superposition diagram, and loop process with arrows and delegation cycles.
Tone: deadpan, procedural, intelligent, cynical but not chaotic.
Style: institutional infographic-poster hybrid, legible hierarchy, muted dark palette, vintage compliance aesthetics.
Message clarity rule: first glance should communicate ownership diffusion and process theater.
No real logos, no copyrighted IP, no real persons.
High resolution vertical composition with clear panel separation.
```

## Negative Constraints

- Avoid explicit violence.
- Do not overpack unreadable text.
- Keep concept understandable without insider context.
- No real company branding or legal marks.

## Variant Prompts

### Variant A: Cleaner Boardroom Diagram

```
Same concept, but use one main boardroom image and one simple side diagram.
Reduce text blocks and increase icon clarity.
Keep headline and one punchline only.
```

### Variant B: Harder Audit Satire

```
Same concept, but intensify the accountability collapse theme.
Include red audit stamps, fragmented ownership tags, and circular sign-off flow.
Punchline line: "Processen fungerar. Resultatet uteblev."
```

### Variant C: Minimal Empty Chair Motif

```
Minimal poster with one chair marked ANSVAR in the center, people around the perimeter passing documents.
One loop arrow system, one top headline, one bottom punchline.
Keep style deadpan and legible.
```
